# Polyglot AI

Learn any language through content you love — gamified daily lessons built from videos,
music, films, books, and podcasts you actually enjoy.

## How it works

1. **Pick a language** you want to learn.
2. **Tell Polyglot what you love** — favourite shows, artists, books, topics.
3. **Take a quick skill assessment** so Polyglot knows where you stand.
4. **Get a daily lesson** crafted from content you care about, at exactly your level.
5. **Build a streak** and watch your fluency grow.

## Tech

- **App**: React Native (Expo) + TypeScript
- **Server**: Java 21 + Spring Boot 3.5 + GraphQL
- **Data**: PostgreSQL 17 (pgvector), MongoDB 8
- **Infra**: Terraform + Ansible + GitHub Actions
